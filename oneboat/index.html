FAQ

Questions, answered

Is OneBoat a note-taking app?

No. OneBoat is the front-door inbox for your notes app. It catches the fragments — screenshots, links, files — so you never lose them, and you keep doing deep work in Notion, Obsidian or Apple Notes. They're partners, not competitors.

Where is my data stored?

All data is stored locally in the app sandbox (SQLite). Optional iCloud backup is available for device-to-device safety. Nothing is uploaded to any server.

Does the AI upload anything?

No. All AI features — OCR, categorization, summaries, tags — run on-device using Apple's frameworks. There is no server call and no network upload.

Which iPhone models and iOS versions are supported?

OneBoat requires iOS 16 or later and runs on iPhone. Widgets need iOS 16.2+.

Can I cancel my subscription?

Yes, anytime — in the App Store's Subscriptions settings. You keep full access until the end of the current period. A one-time Lifetime purchase is also available if you prefer to pay once.

Do I need an account?

No account, no email, no password. Install and start saving.
